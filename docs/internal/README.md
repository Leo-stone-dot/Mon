# Internal Development Notes

本目录保存开发过程材料，不属于面向用户的文档，也不随应用打包发布。

| 文件 | 用途 |
| --- | --- |
| `implementation-notes.md` | agent 执行记录：与原计划的偏离、AI 自行决定的取舍、需要人类复核的点、测试与验证结果。维护规则见仓库根目录 `AGENTS.md`。 |

术语表位于 [`docs/glossary.md`](../glossary.md)，它面向所有贡献者，不属于本目录。

这些材料可能包含本机诊断信息、Space UUID、内部讨论与历史决策。若仓库转为公开项目，可以将整个 `docs/internal/` 目录移入内部分支或独立仓库，不影响用户文档与发布产物。
