# Troubleshooting

## Nothing is working!

Here are some common problems and their solutions.

For macOS 27 bug reports, include exact system and hardware evidence: `sw_vers`,
Mac model/chip, display topology, Separate Spaces, Stage Manager, permission
state, Mon version/build, and the command that failed. Release-candidate
validation sessions should attach the directory generated by
`Scripts/capture-physical-validation-evidence.sh`. See
[macOS 27 Support Guide](macos-27-support.md) for the full evidence, rollback,
TCC reset, and Space degradation checklist.

### "Always float"

Mon has the option to float everything by default until the user manually intervenes. When this mode is unintentionally enabled it can appear that nothing is working. The option is located in settings in the Floating tab and configured with the `floating-is-blacklist` key in a configuration file.

If you have not intentionally enabled this make sure that the option in the Floating tab says "Automatically float applications listed" as in this screenshot.

## One application isn't working!

### "Assign To All Desktops"

macOS has the option to assign an application specifically to no Desktops, one Desktop, or all Desktops. Mon does not handle the last option very well.

To change this setting you can right click (or control click or whatever gesture you may have associated with right click) on the application icon in the Dock. Under Options there is an Assign To section. See the screenshot below for reference.
