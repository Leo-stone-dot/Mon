# Security Policy

## Reporting

This independent fork accepts security observations only through a public
[GitHub issue](https://github.com/Leo-stone-dot/Mon/issues/new). There is no
private security-reporting channel, security email address, or guaranteed
response or resolution time.

Because issues are public, **do not publish secrets, credentials, personal
information, proof-of-concept exploit code, or details that make an unpatched
vulnerability readily exploitable**. If a useful report cannot be made safely
without those details, do not disclose them in this repository. Revoke or rotate
any credential that may already have been exposed.

An issue is an observation for the maintainer, not an assurance that the report
will be investigated, fixed, or released on a particular schedule. Pull requests
are not accepted; maintain your own fork if you need a change on a deadline.

## Scope

Reports about Mon belong in this repository. Reports about upstream Amethyst
belong in the [upstream repository](https://github.com/ianyh/Amethyst). Reports
about Apple platforms or third-party dependencies should be sent to their
respective maintainers using the channels they publish.
